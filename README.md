# Yuva Sampark (BJP Yuva Morcha Tripura Portal)

A modern, full-featured citizen and volunteer empowerment web application built with **Angular (Standalone Components Architecture)** and **Tailwind CSS**.

---

## 🏛️ Application Highlights

1. **Design & Brand Alignment**:
   - Matches the official Yuva Sampark UI theme: Deep Navy (`#0e2554`), Golden Saffron (`#f59e0b`), and pure white surfaces.
   - Hero section featuring **Ujjayanta Palace (Agartala)** lake sunset with an illuminated neon outline map of Tripura state.
   - **10 Core Features Grid** (Member Management, Event Management, Blood Donation, Calling & Messaging, Reports & Analytics, Youth Opportunities, Volunteer Engagement, Announcements, Community Service, My Dashboard).
   - Bottom **"Built for Trust & Security"** banner with the 4 pillars (Role-based Access, Encrypted Data, DPDP Act Compliance, Regular Backup).

2. **Tripura Geographic Hierarchy**:
   - Realistic mock database covering all **8 Districts** (West Tripura, Sepahijala, Gomati, South Tripura, Khowai, Dhalai, Unakoti, North Tripura).
   - Cascading dropdowns dynamically loading all **60 Mandals** and polling booth units.

3. **Emergency Blood Donation Network**:
   - Urgent Blood Request submission form with real-time alerts.
   - Filterable Donor Directory by Blood Group & District with 1-click calling and WhatsApp integration.
   - Blood donation camps and drives with live donor pledge counters.

4. **Tripura State & Central Schemes Hub**:
   - Mukhyamantri Yuva Yogayog Yojana (Smartphone scheme).
   - Mukhyamantri B.Ed. Anuprerana Yojana.
   - Tripura Youth Entrepreneurship Scheme (TYES) / PMEGP.
   - North Eastern Council (NEC) Merit Scholarships.
   - Interactive detail modals with eligibility checklists and required documents.

5. **Member Onboarding & KYC**:
   - 4-Step reactive registration form with real-time validation.
   - Digital Personal Data Protection (DPDP Act 2023) consent flow.
   - Post-registration success screen displaying Application ID (`TR-YUV-2026-XXXX`) and an interactive, printable **Digital Membership Card** with QR verification.

6. **Role-Based Access Control (RBAC)**:
   - Super Admin -> State Admin -> District Admin -> Mandal Admin -> Member.
   - Interactive role switcher in the dashboard to test each level's perspective.

## 🚀 Running the Project

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the local development server**:
   ```bash
   npm start
   # or
   ng serve
   ```

3. **Open the application**:
   Navigate in your browser to `http://localhost:4200/`.
